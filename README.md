## Implemented Components
- Linked List – student record storage and add/update/delete/display
- Stack – recent action history
- Queue – student service requests
- BST – student organization/display by Student ID
- Hashing – efficient Student ID search
- Graph – campus locations and connections using an adjacency list
- BFS – campus network traversal
- Input validation and error handling
- Menu-driven Java console interface

## Requirements
- Java JDK 17 or later
- Any Java IDE (Eclipse, IntelliJ IDEA, NetBeans, or VS Code) or terminal

## Run from terminal
From the project folder:

```text
javac -d out src/*.java
java -cp out Main
```
